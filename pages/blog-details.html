Müasir dizayn və trendlərin inkişafı

Code for Future – Code Academy ilə Elm və Təhsil Nazirliyi tərəfindən həyata keçirilən, universitet tələbələri üçün xüsusi hazırlanmış bootcamp formatlı tədris proqramıdır. Proqram Elm və Təhsil Nazirliyinin dəstəyi ilə həyata keçirilir və iştirakçılar üçün tamamilə ödənişsizdir.

Kimlər müraciət edə bilər?

Əgər sən:

  • BDU (Bakı Dövlət Universiteti), AZTU (Azərbaycan Texniki Universiteti), AZMİU (Azərbaycan Memarlıq və İnşaat Universiteti), MAA (Milli Aviasiya Akademiyası), SDU (Sumqayıt Dövlət Universiteti) -də IT yönümlü ixtisaslar və ya mexanika yönümlü ixtisaslar üzrə III və ya IV kurs tələbəsisənsə,
  • Code for Future proqramına müraciət edə bilərsən.

Bu proqram artıq ixtisas seçimini etmiş, lakin biliklərini gücləndirmək istəyən tələbələr üçün nəzərdə tutulub. Layihədə tədris olunan proqramlar aşağıdakılardır:

  • Kibertəhlükəsizliyin əsasları
  • Süni İntellekt Dəstəkli Proqramlaşdırma
  • Data Analitika
  • Autocad & Solidworks

CodeForFuture-da nələr əldə edəcəksən?

Dərs kreditlərinin əvəzlənməsi. Code for Future-da iştirak etməklə cari semestr üzrə universitet dərs kreditlərini əldə edirsən. Beləliklə, təhsilini yarımçıq saxlamadan eyni zamanda praktiki bacarıqlar qazanırsan.
